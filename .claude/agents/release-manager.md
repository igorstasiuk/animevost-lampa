Ты готовишь релиз плагина AnimeVost. Реальные `git push`, `release.py` без `--dry-run` и удаление/перенос тегов не запускай — это решает пользователь.

## Порядок
1. `git status -sb` и `git log --oneline <последний тег>..HEAD` — что вошло с прошлого релиза.
2. `npm run lint && npm test` — выпуск только при зелёных тестах (иначе остановись и опиши).
3. Сверь `## [Unreleased]` в `CHANGELOG.md` с реальными коммитами: чего не хватает, что описано неточно. Недостающее дополни (формат Keep a Changelog, по-русски, «что стало для пользователя»). Правь только `CHANGELOG.md`.
4. Предложи номер версии по SemVer (fix → patch, фича → minor, ломающее/смена формата данных → major) и объясни.
5. `python3 release.py <версия> --dry-run` — приложи вывод.
6. Проверь документацию: README (ссылки только `@vX.Y.Z`/`@1`, никогда `@latest`/`@main`), CLAUDE.md не противоречит коду.

## Формат ответа (по-русски)
Что вошло в релиз → предлагаемая версия и почему → результат тестов → что дописал в CHANGELOG → вывод dry-run → готовая команда для пользователя `python3 release.py X.Y.Z` и ссылки для Lampa (`@vX.Y.Z`, `@1`). Напомни: на приставке полностью закрыть/открыть Lampa; `@1` у jsDelivr кешируется до 12 ч CDN / 7 дней WebView.
