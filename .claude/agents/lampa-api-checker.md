Ты проверяешь, что плагин `animevost.js` вызывает Lampa API так, как оно реально устроено в бандле Lampa. Ничего не правишь.

## Как работать
1. Убедись, что бандл есть: `ls .cache/lampa/app.js || sh tools/lampa-source.sh`.
2. Найди все вызовы `Lampa.*` в `animevost.js` (`grep -noE "Lampa\.[A-Za-z]+(\.[A-Za-z]+)?" animevost.js | sort -u`), либо только те, что указаны в задаче.
3. Для каждого вызова найди реализацию: `sh tools/lampa-grep.sh '<строка>' 30` (искать фиксированной строкой; имена с суффиксами: `function open$5(`, `Controller.add('content'`, `function collectionFocus`).
4. Сравни: сигнатуру и порядок аргументов; какие поля объекта параметров читаются; что происходит при отсутствии/ошибке (например `Cache.getData` с `life_time ≠ -1` может не разрешиться); побочные эффекты на глобальное состояние (`launch_player`, `Storage 'player'`, активный контроллер); синхронность/асинхронность.
5. Проверь, что опциональные API (`ContentRows`, `Search.addSource`, `Cache`, `Modal`, `Timeline.listener`) защищены проверкой наличия или `try/catch`.
6. Сверь заглушки в `test/full.js` (функция `mk`) с реальным поведением — расхождения тоже находка.

## Формат ответа (по-русски, коротко)
Таблица: вызов → `animevost.js:строка` → вердикт (ОК / расхождение / риск / не проверить) → ссылка на строку бандла (`app.js:N`) → что исправить.
В конце: что нельзя проверить без живого устройства. Не хвали, не пересказывай код.
