# Тесты

- `npm test` → `test/full.js`: jsdom, заглушка Lampa, живой API AnimeVost. Каждая фича и багфикс UI — новый нумерованный сценарий (см. шапку файла), включая негативные: мёртвый API (`mk('http://127.0.0.1:9/v1')`), уничтожение страницы во время загрузки, быстрые повторные действия.
- Ожидание асинхронщины — `until(() => условие)` с таймаутом; **циклы навигации всегда с ограничением по числу итераций** (бесконечный `while` по `S.label()` однажды съел всю память).
- Заглушки в `mk()` повторяют реальное поведение Lampa (`Storage.get` приводит `'false'` к `false`, `Controller.collectionFocus` триггерит `hover:focus`). Меняешь поведение Lampa-вызова — сначала сверь с бандлом и поправь заглушку.
- Чистые функции тестируются прямо через `require('../animevost.js')` на живых данных API (разные тайтлы: длинные франшизы, без дат, с двоеточием/скобками, 200+ серий).
- Что jsdom не покрывает (раскладка, реальный фокус на ТВ, внешний Android-плеер, IndexedDB на приставке, нативный запрос сайта) — явно перечислять в отчёте как «не проверено на устройстве».
- Не запускай локальный HTTP-сервер и не открывай `file:` в браузерных инструментах, если среда это блокирует — не обходи запрет.
