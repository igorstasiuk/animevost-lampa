# Ченджлог и релизы

- Любое пользовательское изменение сразу попадает в `## [Unreleased]` файла `CHANGELOG.md` под `### Добавлено / Изменено / Исправлено / Удалено`: одна строка = что стало для пользователя (не «рефакторинг X»). Русский язык, без номеров коммитов.
- Версия в трёх местах должна совпадать после выпуска: `var VERSION` в `animevost.js`, верхняя секция `CHANGELOG.md`, git-тег `vX.Y.Z` (+ `latest` на том же коммите). Проверка: `npm run check`. Версию руками не правь — это делает `release.py`.
- SemVer: patch — исправления, minor — новые фичи, major — ломающие изменения (например, смена формата `animevost_state`).
- Ссылки в документации и ответах пользователю: `@vX.Y.Z` или `@1`. **Не `@latest`, не `@main`** (jsDelivr кеширует их неизменяемо/на дни).
- Выпуск — исходящее действие (push, force-push `latest`): сначала `python3 release.py X.Y.Z --dry-run`, затем спросить подтверждение у пользователя.
- Меняется формат данных в Storage/IndexedDB (`animevost_state`, `animevost_pl_*`, …) — добавь миграцию/совместимость и запись в CHANGELOG.
