# Добавить фичу / исправить баг в плагине

Работай по шагам; не пропускай проверки — на ТВ ошибки видны только пользователю.

1. **Понять задачу и место в коде.** Карта файла — в `CLAUDE.md` (блоки: чистые функции / Storage / сеть / плеер / UI / регистрация). Новая логика без Lampa — в чистые функции (их можно тестировать в node).
2. **Проверить Lampa API** для каждого нового вызова: `sh tools/lampa-grep.sh '<строка>' 25` (или агент `lampa-api-checker`). Опциональные API — с проверкой наличия и `try/catch`.
3. **Писать в стиле файла** (ES5, см. `.claude/rules/es5-webview.md`): `var`, `function`, `$.ajax` через `request()`, данные из API в DOM только `.text()`/`.attr()`.
4. **Если затронут экран/фокус** — следовать `.claude/rules/tv-navigation.md`: контроллер `content`, ряды в `Grid`, окна возвращают `toggle('content')`, пустого экрана нет, колбэки проверяют `destroyed`/`token`. После — агент `tv-nav-reviewer`.
5. **Тест**: добавь сценарий(и) в `test/full.js` (позитивный + негативный: мёртвый API, destroy во время загрузки). `npm run lint && npm test` — зелёный. Агент `plugin-qa` может дописать пропущенные сценарии.
6. **ES5-сканер**: `grep -nE "=>|\blet |\bconst |\`|\.includes\(|\.findIndex\(|Object\.assign|Array\.from|gap:" animevost.js` — пусто.
7. **CHANGELOG**: строка в `## [Unreleased]` (Добавлено/Изменено/Исправлено), по-русски, что стало для пользователя. Формат данных в Storage поменялся — миграция + запись.
8. **README/CLAUDE.md**: обнови, если изменилось поведение для пользователя или карта кода.
9. **Отчёт пользователю — честно**: что проверено тестами, что только по исходникам Lampa, что не проверить без устройства (раскладка, реальный фокус ТВ, внешний плеер, IndexedDB на приставке). Не писать «проверено», если проверено только в jsdom.
10. Коммит — коротким сообщением по сути; push/релиз — только после подтверждения пользователя (`/release`).
