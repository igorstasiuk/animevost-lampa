# AnimeVost для Lampa

Плагин добавляет в меню Lampa пункт **AnimeVost** — отдельную страницу:

- **Дашборд онгоингов** по дням недели (сегодня первым), карточки с постером и номером ближайшей серии. Последний раздел — «Без даты выхода».
- **Адаптивная сетка**: аниме в каждом дне показываются сеткой с переносом строк (число колонок зависит от ширины экрана — от телефона до 4K ТВ), серии — одной полосой с прокруткой.
- **Продолжить просмотр** — ряд сверху с тайтлами из истории.
- **Страница тайтла**: описание, список серий с превью, прогресс-бар и «Остановились на 10:12». Кнопка «Продолжить» сама выбирает недосмотренную серию или следующую после досмотренной.
- **Время до следующей серии** на странице тайтла («6 серия выйдет через 6 д 21 ч»). Точное время берётся из поля `timer`, если его нет — считаем дни по дате из заголовка.
- **Сезоны, фильмы, ОВА**: рядом с «Смотреть» кнопка-выпадающий список («2 сезон ▾») со всеми частями франшизы; выбор заменяет страницу на месте. API связей не отдаёт, поэтому плагин ищет по названию без суффиксов («(второй сезон)», «ОВА-1», «(фильм первый)») и подзаголовка после «:» и оставляет совпадения по этому ключу (кеш 7 дней). У нестандартных названий (например «Судьба:» с несколькими подфраншизами) возможны лишние или пропущенные части.
- **Отметки просмотра**: долгое нажатие OK на тайле серии (или правая кнопка мыши) — «просмотрено / не просмотрено», «просмотрено всё до этой», сброс прогресса серии или всего тайтла. Работает через `Lampa.Timeline`.
- **История**: долгое нажатие на карточку в «Продолжить просмотр» — удалить или очистить. На карточке полоска прогресса и бейдж «+N новых», если с последнего просмотра вышли новые серии.
- **Описание** целиком — кнопка «Описание» (окно Lampa). **Карточка Lampa** — открывает поиск Lampa/TMDB по английскому названию, оттуда можно добавить тайтл в закладки.
- **Длинные тайтлы** (сотни серий) разбиты на страницы по 50: выпадающий список «Серии 1–50 ▾» и «Перейти к серии №…».
- **Главный экран Lampa**: ряды «AnimeVost: продолжить просмотр» и «AnimeVost: сегодня выходит» (включаются/выключаются в настройках Lampa → интерфейс → строки главной).
- Прогресс на странице тайтла обновляется сам при любом обновлении таймкода (автопереход, внешний плеер, другое устройство через CUB).
- Тяжёлые кеши (списки серий, дашборд) лежат в IndexedDB через `Lampa.Cache`, а не в localStorage.
- **Запоминание**: список серий кешируется (работает офлайн, если API недоступен), таймкод хранится в `Lampa.Timeline` — в той же базе, что и у обычных фильмов Lampa, поэтому синхронизируется с CUB-аккаунтом.
- **Выбор плеера**: настройки → AnimeVost → «Плеер», либо кнопка «Плеер» на страницах. Можно включить «спрашивать при каждом запуске».
- **Поиск**: кнопка «Поиск» на дашборде (результаты рядами, дальше всё как у обычного тайтла: серии, прогресс, плеер) и отдельный источник «AnimeVost» в общем поиске Lampa (лупа в шапке) — результаты идут рядом с TMDB.
- Выбор качества (720p/480p), смена адреса API.

## Файлы

| Файл | Что это |
|---|---|

## Как подключить в Lampa

Плагин подключается по URL: **Настройки → Расширения → Добавить плагин** → вставить ссылку на `animevost.js` → перезапустить Lampa.

Ссылка должна быть доступна устройству, на котором запущена Lampa. Варианты:

### А. Для постоянного использования — GitHub + jsDelivr (HTTPS)

1. Создай репозиторий, положи туда `animevost.js`.
2. Ссылки по тегам (версии — в [CHANGELOG.md](CHANGELOG.md), список — во вкладке Tags):
   - **Всегда последняя версия 1.x**: `https://cdn.jsdelivr.net/gh/<user>/<repo>@1/animevost.js` — jsDelivr сам подставляет самый новый тег `1.x.x` (CDN кеширует до 12 часов, браузер/WebView приставки — до 7 дней).
   - **Конкретная версия** (обновляется на устройстве сразу, не кешируется): `https://cdn.jsdelivr.net/gh/<user>/<repo>@v1.0.0/animevost.js`.

   Git-тег `latest` всегда указывает на последнюю версию (удобно для `git checkout latest` и сравнений на GitHub), но **в ссылке jsDelivr его использовать нельзя**: jsDelivr принимает тег `latest` за версию и отдаёт его как неизменяемый с кешем на год, поэтому `@latest` перестанет обновляться. Для автообновления бери `@1`.

   Если нужно обновиться на устройстве немедленно — используй ссылку с конкретным тегом и замени её в Lampa (Настройки → Расширения → удалить плагин → добавить новый → перезапустить Lampa). Версию установленного плагина видно в Настройки → AnimeVost → «Версия плагина».
3. Вставь её в Lampa.

Это единственный вариант, если Lampa открыта по `https://` (lampa.mx и т.п.): браузер не даст загрузить скрипт по `http://`.

### Б. Для разработки — локально по LAN

```bash
python3 ~/lampa-animevost/serve.py
```

Скрипт напечатает ссылку вида `http://192.168.x.x:8099/animevost.js` — её и добавляй в Lampa. Работает для Lampa на ТВ/телефоне в той же сети, если сама Lampa открыта по `http://` (приложения Android/Tizen/webOS подходят, `https://lampa.mx` в браузере — нет). Правки в файле подхватываются после перезапуска Lampa.

## Устройства и управление

- **Android TV / приставки, Tizen, webOS** — управление пультом: стрелки двигают фокус по рядам (кнопки → сезоны → серии), OK открывает, «Назад» возвращает. Серии — одна строка больших тайлов с горизонтальной прокруткой. Для Android TV в выборе плеера доступен «Внешний (Android / Lampa)» — он отдаёт видео системному плееру и возвращает позицию.
- **Mac / ПК (браузер или приложение Lampa)** — работают клавиатура (стрелки, Enter, Esc), мышь (наведение, клик, колесо) и тачпад. В списке плееров — IINA, mpv, Infuse, nPlayer, SenPlayer.
- **iPhone / iPad / Apple TV** — VLC, Infuse, nPlayer, SenPlayer.
- В диалоге выбора показываются только плееры, подходящие устройству.

## Плееры — что важно знать

| Выбор | Поведение | Таймкод |
|---|---|---|
| Как в настройках Lampa | используется глобальная настройка плеера | зависит от плеера |
| Встроенный | плеер Lampa | да, возобновляет с места остановки |
| Внешний (Android / webOS) | Lampa отдаёт ссылку системному плееру | да на Android (Lampa получает позицию; экран тайтла обновляется, когда окно снова становится видимым) |
| VLC / Infuse / IINA / mpv / nPlayer / SenPlayer | открывается через URL-схему (`vlc://`, `infuse://`…) | **нет** — внешняя программа не сообщает позицию |
| Скопировать ссылку | ссылка на видео в буфер | нет |

Схемы работают на тех платформах, где их поддерживает сама Lampa: iOS/tvOS (VLC, Infuse, nPlayer, SenPlayer…), macOS (IINA, mpv, Infuse…). Для схем плагин на ~5 секунд подменяет глобальную настройку `player` и затем возвращает прежнее значение.

## Как это устроено

API `https://api.animevost.org/v1` (CORS открыт):

| Метод | Для чего |
|---|---|
| `GET /last?page=N&quantity=40` | последние обновления → источник онгоингов |
| `POST /search` `name=` | поиск |
| `POST /info` `id=` | карточка тайтла |
| `POST /playlist` `id=` | серии: `name`, `std` (480p), `hd` (720p), `preview` |

Расписания в API нет, поэтому дашборд дополнительно читает официальное расписание с главной animevost.org (дни и время выхода, московское; кеш 3 часа). Сайт не отдаёт CORS-заголовки: на Android/Android TV Lampa делает запрос нативно, а в браузере нужен CORS-прокси в настройках («CORS-прокси для расписания»). Если расписание получить не удалось, день недели берётся из заголовка тайтла (`[7 серия - 8 ноября]`), а если там нет даты — из поля `timer` (unix-время следующей серии). Всё без даты и с пометкой «N из M+» попадает в «Без даты выхода». Если день определяется неверно — смотри `parseAnime()` в начале файла (функция не зависит от Lampa и проверяется в node).

Ключи в Lampa.Storage: `animevost_state` (история и последняя серия), `animevost_pl_<id>` (кеш списка серий), `animevost_rel_<ключ>` (кеш франшиз), `animevost_cache_last` (кеш дашборда, 30 мин, без описаний), `animevost_schedule` (расписание сайта, 3 ч), плюс настройки `animevost_*`. При старте плагин удаляет записи `animevost_pl_*`/`animevost_rel_*` старше 30 дней и оставляет не больше 40 кешей серий. Таймкоды — в общем хранилище `Lampa.Timeline` (хеш `animevost:<id>:<серия>`).

## Ограничения

- Расписание приблизительное — как у самого сайта: дата серии бывает устаревшей.
- Если у сети/провайдера блокируется `api.animevost.org`, укажи зеркало или прокси в настройках «Адрес API».
- Видео отдаётся с `video.animetop.info`; плагин по умолчанию переписывает `http://` на `https://`. Если хост у тебя не открывается по https — выключи «Принудительно HTTPS» в настройках.
- Плагин проверен в jsdom с заглушкой Lampa и по исходникам актуального `app.min.js`; на живой Lampa (особенно пультовая навигация на ТВ) стоит пройтись руками.


## Известные ограничения

- Постеры `static.openni.ru` отдаются с просроченным https-сертификатом: плагин пробует оригинал → другую схему → прокси `images.weserv.nl` (сторонний сервис видит запрос картинки). Рабочий вариант запоминается на сессию.
- Расписание сайта в браузере требует CORS-прокси (на Android Lampa получает его нативно).
- Тайтлы на 1000+ серий (One Piece) создают тысячи тайлов сразу; ленивая подгрузка — в планах.

## Релизы

Каждая версия — git-тег `vX.Y.Z` с заметками из [CHANGELOG.md](CHANGELOG.md); тег `latest` всегда указывает на последнюю (для jsDelivr используй `@1` или `@vX.Y.Z`, не `@latest`).

```bash
# 1. опиши изменения в разделе «## [Unreleased]» файла CHANGELOG.md
# 2. выпусти версию (по SemVer: исправление — patch, новая фича — minor, ломающее — major)
./release.py 1.1.0 --dry-run   # посмотреть, что будет сделано
./release.py 1.1.0             # версия в коде + ченджлог + коммит + тег + latest + push + purge jsDelivr
./release.py --check           # проверить согласованность VERSION / CHANGELOG / тега / latest
```

Скрипт отказывается работать, если не на `main`, есть незакоммиченные изменения, версия не больше последнего тега или раздел `[Unreleased]` пуст.
